# 🏏 Cricsheet Match Data Analysis

## 📌 Project Overview
This project analyzes cricket match data from Cricsheet using Selenium, Python, SQLite, SQL, Exploratory Data Analysis (EDA), and Power BI. The complete workflow covers data collection, preprocessing, database creation, SQL analysis, visualization, and dashboard development.

---

## 🎯 Objectives
- Scrape cricket match data from Cricsheet.
- Process nested JSON files into structured data.
- Store data in SQLite database.
- Perform SQL-based analytics.
- Conduct Exploratory Data Analysis (EDA).
- Build an interactive Power BI dashboard.

---

## 📂 Dataset
Source: **Cricsheet**

Formats Included:
- ODI
- Test
- IPL
- International T20

Dataset Summary:
- Total Matches: **5,641**
- Ball-by-Ball Deliveries: **3.8 Million**
- Match Formats: **4**

---

## 🔄 Project Workflow

1. Web Scraping using Selenium
2. Download JSON files
3. Extract and preprocess data
4. Store data in SQLite
5. Execute SQL analysis
6. Perform EDA using Python
7. Build Power BI dashboard

## 📊 Key Insights

- Australia recorded the highest number of match wins.
- Virat Kohli is the highest run scorer.
- James Anderson took the most wickets.
- ODI is the most frequently played format.
- Harare Sports Club hosted the highest number of matches.
- Teams slightly prefer fielding after winning the toss.
